# 액션 플로우 맵 (피그마 화면 흐름 ↔ 구현)

> 피그마 high_fi_wireframe이 화면 순서로 보여주는 사용자 흐름을, 실제 라우팅/액션과
> 대조한 지도. 피그마엔 프로토타입 링크가 없어 화면 이름·팀 주석으로 흐름을 재구성.
> 최종 갱신: 2026-07-25. 상세 스펙은 [[FIGMA_NOTES]], [[SPEC]].

## 전체 흐름도

```
[랜딩 /]
   │ 지금 시작하기 / 로그인
   ▼
[로그인 login] ──회원가입──> [회원가입 signup_01] ──(가입)──> 
   │ (인증)                                              │
   │  비밀번호 찾기 → [forgot-password] → 메일 → [reset-password]
   ▼                                                     ▼
[홈 대시보드 main] ◀───────────────────────────────────┘
   │
   ├─ 학업 현황 카드 ─────────────────────┐
   ├─ 커리큘럼 계획 → [커리큘럼 /curriculum]
   ├─ 추천 선배 '지금 연결하기' → [선배 상세 /seniors/:id]
   │
   ├─(네비) 커리큘럼 계산기 → [/curriculum]
   ├─(네비) 선배와의 연결 ▾ → [선배 탐색 /explore] · 커피챗 관리 → [/my]
   ├─(네비) 커리어 로드맵 ▾ → [로드맵 탐색 /roadmaps] · 내 로드맵 → [/roadmap]
   ├─(네비) 메시지함 → [/my]
   ├─(네비) 🔔 알림 → 클릭 시 [/my]
   └─(네비) 프로필 → [마이페이지 /my]

[선배 탐색 /explore]
   │ 프로필 보기 / 카드 클릭
   ▼
[선배 상세 /seniors/:id]  (mentor_profile)
   │ 북마크 ★ 토글 (즐겨찾기)
   │ '선배와 연결하기' → [커피챗 신청 모달]
   ▼
[커피챗 신청] ──(선배 수락, 알림)──> [마이페이지 커피챗 관리]
                                          │ '채팅 열기'
                                          ▼
                                    [채팅 모달 mentor_chat]

[커리큘럼 /curriculum]
   │ 카테고리 탭(전공기초/필수/산학필수/선택) 전환 → 과목 체크 → 학점 계산(실시간)

[마이페이지 /my]
   ├─ 프로필 수정 (모달)
   ├─ 스크랩북(즐겨찾기 선배)
   └─ 커피챗 관리(받은/보낸) → 채팅
```

## 팀 주석이 명시한 액션 (구현 상태)

| 피그마 주석 | 흐름 | 상태 |
|---|---|---|
| "선배에게 질문하기 누르면 → 선배 프로필 → 메세지함으로 이어지게" | 탐색→상세→커피챗→(수락)→채팅 | ✅ 연결됨 (수락은 비동기+알림) |
| "계산하기 누르면 로딩/'잠시만 기다려주세요'" | 커리큘럼 계산 피드백 | ❌ 로딩 표시 없음 (학점은 실시간 계산) |
| "스크롤 시 상단 졸업요건 고정, 하단 리스트만" | 커리큘럼 sticky | ❌ 현재 좌/우 레이아웃 |
| "리스트 5개 보이고 넘으면 스크롤" | 목록 높이 | 🚧 overflow는 있음 |
| "메인 디폴트 = 계산 전 zero state" | 홈 초기 상태 | ✅ |
| "마이페이지: 프로필 수정 + 즐겨찾기" | 마이페이지 | ✅ |

## 구현된 네비게이션 (코드 기준)

- 로그인/회원가입 → `/home`
- 홈: 추천선배 '지금 연결하기'→`/seniors/:id`, 커리큘럼 계획→`/curriculum`, 선배 찾기→`/explore`
- 네비 드롭다운: 선배와의 연결▾(선배 탐색/커피챗 관리), 커리어 로드맵▾(로드맵 탐색/내 로드맵)
- 네비 메시지함·알림 클릭 → `/my`
- 선배 카드 → `/seniors/:id`, 상세 '선배와 연결하기' → 커피챗 모달
- 커피챗 수락 → '채팅 열기' → 채팅 모달
- 비밀번호 찾기 → `/forgot-password` → 메일 → `/reset-password`
